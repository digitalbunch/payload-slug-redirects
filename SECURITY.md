# Security policy

## Reporting a vulnerability

If you find a security vulnerability in this package, please report it privately by emailing security@digitalbunch.com instead of opening a public issue.

We will acknowledge your report within 48 hours and aim to release a fix within 7 days for confirmed vulnerabilities.

## Supported versions

Only the latest major version receives security updates.

| Version | Supported |
|---------|-----------|
| 2.x     | Yes       |
| 1.x     | No        |
